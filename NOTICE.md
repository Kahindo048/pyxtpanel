# Notice: credits, sources and what is not copied

`pyxtpanel` is distributed under the MIT licence ([LICENSE](LICENSE)). This notice says where its
formulas, numbers and ideas come from, so that nothing is taken for original that is not.

## 1. No Stata code

* **No source code of Stata is included or translated.** No `.ado`, no Mata source, no part of the
  Stata program is in this package, its tests or its documentation. The Python code is written from
  the published formulas and from the behaviour observed by running Stata.
* **The formulas** come from the published papers and books cited in the docstring of each function
  and in `docs/documentation.md` (part 9 and annex B), and from the public documentation of Stata
  (the `[XT]` and `[TS]` manuals). A formula is not code.
* **The conventions of Stata** that the package reproduces (annex D of the documentation) were
  identified by running Stata 17 MP on test panels. For a few commands the installed `.ado` files
  were also read to learn which convention applies when the manual does not say (for example the order
  of `xtdescribe` patterns); the comments of the modules name them. Each convention is checked
  by a case run in Stata and frozen in `tests/golden/`.
* **Stata is used as a reference, not shipped.** `validation/` holds the do-files and the runner;
  `tests/golden/` holds the numbers Stata returned. Stata is a registered trademark of StataCorp
  LLC. This package is not affiliated with, endorsed by or sponsored by StataCorp.

## 2. Numerical tables embedded in the package

The statistical tests of unit roots, cross-sectional dependence and cointegration need tables of
numbers that were published in papers. They are in `src/pyxtpanel/_data/tables/`, each with its
source, date, check and SHA-256 in [MANIFEST.json](src/pyxtpanel/_data/tables/MANIFEST.json), which
is verified every time a table is loaded. They are numbers (facts), not code. How they were obtained,
stated plainly:

| Table | Published source | How the numbers were obtained |
|---|---|---|
| `mackinnon_adf.csv` | MacKinnon (1994), J. Business & Economic Statistics 12(2) | Coefficients of the paper, compared with `statsmodels` and Stata |
| `llc_adjustments.csv` | Levin, Lin and Chu (2002), J. Econometrics 108(1), Table 2 | Read from the values compiled in Stata 17's `_xturllc.ado` (no readable copy of the paper) |
| `ips_table1.csv`, `ips_table2.csv`, `ips_table3.csv` | Im, Pesaran and Shin (2003), J. Econometrics 115(1), Tables 1 to 3 | Read from the values compiled in Stata 17's `_xturips.ado` (no readable copy of the paper) |
| `frees_q.csv` | Frees (1995), J. Econometrics 69(2); Frees (2004) | Read from the user-written `xtcsd.ado` (De Hoyos and Sarafidis 2006) |
| `cips_moments.csv`, `cips_critical.csv` | Pesaran (2007), J. Applied Econometrics 22(2), Tables I and II | Read from the user-written `pescadf.ado` (Lewandowski 2006, extended by W. Hoelzl); the critical values were compared cell by cell with `plm::cipstest` (767 of 768 cells identical) |
| `westerlund_moments.csv` | Westerlund (2005), Econometric Reviews 24(3) | Deduced from the numerical output of `xtcointtest westerlund` on simulated panels (not read from code) |
| `pedroni_moments.csv` | Pedroni (1999), Oxford Bull. Economics & Statistics 61; Pedroni (2004), Econometric Theory 20 | Deduced from the numerical output of `xtcointtest pedroni` on simulated panels (not read from code) |

Where a table was read from an `.ado` file, only the published numbers were taken, not the program
around them; every table is checked end to end by Stata cases in `tests/golden/`. The numbers of the
tables not compared with the paper itself are marked so in the manifest, and they reproduce Stata,
including two known oddities that Stata carries (one cell of IPS table 3, one sign of the Pedroni
`panel_rho` mean), which the manifest and the result notes name.

## 3. Code reused

* **`pyxtdpthresh`** (same author): the grammar of the time-series operators (`pyxtpanel.ops.parse`,
  52 spellings validated against Stata) and the look of the figures (`pyxtpanel.plot.style`).
* **`pandas`, `numpy`, `scipy`** (BSD-3-Clause) are dependencies, not copied; **`matplotlib`**
  (matplotlib licence, BSD-style) is the optional dependency of the figures.
* **Equivalents named in the documentation** (annex A: Stata, R `plm`, `expdpy`, `panelView`,
  `linearmodels`) are mentioned for the user's orientation. No code of these packages is copied; `plm`
  and `statsmodels` were used as independent references to cross-check some formulas and tables.

## 4. Data

* `tests/` and `validation/` use **simulated panels** generated by the repository.
* `validation/data/invest.dta` and its copy `examples/data/hansen_1999_invest.dta` are the firm
  investment panel of Hansen (1999), *Threshold effects in non-dynamic panels*, J. Econometrics
  93(2), as distributed by its author; they are used only by the tests and the examples and are
  **not** part of the wheel or the source distribution.
* The Stata sample dataset `nlswork` (StataCorp) is **not** redistributed; no example needs it.
